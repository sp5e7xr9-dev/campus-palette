# 追加Excelの照合・収録範囲

## 追加Excelの反映（2026年11月18日）

14大学・904件に更新しました。新潟184，埼玉162，弘前144，岩手140，山形105，東京都立48，秋田26，福島25，宇都宮24，東京薬科15，帯広畜産12，東北12，宮城6，千葉1件です。

- 弘前は2024・2025年度も原本表から抽出。2024年度共通テストは全学900点満点、2025年度以降は人文社会科学部900点・その他1000点。資料の書式差を確認しました。
- 岩手・山形は3年度の一般選抜表を抽出。不開示行を含め、原本の募集単位・改組を維持。山形の社会共創デジタル学環は学環一括の公表です。
- 宇都宮は2027年度募集要項の物理57ページにある2026年度合格者成績。24募集単位の共通・個別を区別し、少人数非公表を保持。
- 東北は2024〜2026年度の理・工・農（理学部後期を含む）の満点のみ。合格者最高・最低・平均は未確認。2024年度PDFは大学名・年度のある公式募集要項を配信サービスweb-pamphlet.jpから取得したものです。許可ホストを明示。2025・2026年度はアドミッション機構の公式ホスト。
- 秋田はExcelの78行・26募集単位の数値を原本画像で照合。2024年p1、2025年pp1-2、2026年pp1-2。スキャンPDFに文字層がない年度は、照合済み部分の数値スナップショットとPDFのSHA-256を保持。元PDFが変わると解析を停止し、再度原本画像の確認を求めます。未抽出の募集単位は未収録です。
- 帯広畜産は同一公式PDFの年度欄から3年度を分離。2025年度の配点変更を保持。最低・平均は追加合格者除外。
- 福島は2026年度の総合最低点を追加。学類一括はコースに分配しません。満点が書かれていない欄は空欄。
- 千葉は2026年度看護学部の公式HTMLだけ照合できました。2024・2025年度の全学得点PDF4本はHTTP 503/502等で取得できず、数値は公開JSONへ入れていません。資料未確認を非公表と表現していません。
- 埼玉・東京都立の添付行は既存原本データと重複するため再追加しません。新潟・宮城・東京薬科も従前の照合済み値を保持。
